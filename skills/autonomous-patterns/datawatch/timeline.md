# timeline

Show the Automata timeline for the project.

1. **Scope it before you run it.** An unfiltered timeline is about 260,000 tokens (a project about 177,000, a kind about 139,000). Run `datawatch autonomous timeline --automaton <id>` for one Automaton (about 400 tokens) or a stage. If the operator wants the whole project, give `datawatch autonomous progress` (about 1,500 tokens) and the brief's running list, and offer to draw one Automaton or a stage. It draws work, blocked time, today and the projected finish as text bars.
2. Add a short reading in plain words: what is on the critical path, what is blocked and for how long, and when the projected finish falls against the week's pace line.
3. Name anything that is blocked by a held item and point to `holds.md`.
4. If the operator named an Automaton or a stage, narrow to it. Do not start or change anything.
