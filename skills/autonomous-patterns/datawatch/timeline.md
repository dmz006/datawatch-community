# timeline

Show the Automata timeline for the project.

1. Run `autonomous_timeline` for the project (or `datawatch autonomous timeline --automaton <id>` for one Automaton). It draws work, blocked time, today and the projected finish as text bars.
2. Add a short reading in plain words: what is on the critical path, what is blocked and for how long, and when the projected finish falls against the week's pace line.
3. Name anything that is blocked by a held item and point to `holds.md`.
4. If the operator named an Automaton or a stage, narrow to it. Do not start or change anything.
