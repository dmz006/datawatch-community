# sync plugins

Plugins for workspace and file synchronization across federated datawatch instances.

| Plugin | Description |
|--------|-------------|
| [workspace-rsync-sync](workspace-rsync-sync/) | Rsync-based workspace mirroring over SSH |
| [workspace-git-sync](workspace-git-sync/) | Git remote pattern for workspace sync |

These complement the core **BL333 Federated File Service** (v8.3.0+) for teams that prefer
a filesystem-native sync approach without requiring full federation setup.
